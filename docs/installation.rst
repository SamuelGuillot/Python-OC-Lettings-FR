Installation
============

Prérequis
---------

- Python 3.12
- Poetry
- Git

Étapes
------

.. code-block:: bash

   git clone https://github.com/SamuelGuillot/Python-OC-Lettings-FR.git
   cd Python-OC-Lettings-FR
   poetry install

Créez un fichier ``.env`` à la racine :

.. code-block:: ini

   DEBUG=True
   SECRET_KEY=dev-only-insecure-key
