Technologies
============

- **Langage** : Python 3.12
- **Framework** : Django 5.2
- **Base de données** : SQLite (local) / PostgreSQL (production)
- **Gestionnaire de dépendances** : Poetry
- **Conteneurisation** : Docker
- **CI/CD** : GitHub Actions
- **Déploiement** : Render
- **Monitoring** : Sentry
