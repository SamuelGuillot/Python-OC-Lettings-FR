Guide d'utilisation
===================

Cas d'utilisation
-----------------

**Consulter les locations**
   1. Ouvrir ``/lettings/``.
   2. Cliquer sur une location pour voir son adresse.

**Consulter les profils**
   1. Ouvrir ``/profiles/``.
   2. Cliquer sur un profil pour voir sa ville favorite.

**Administration**
   1. Se connecter à ``/admin/`` avec un compte superuser.
   2. Gérer les adresses, locations et profils.
